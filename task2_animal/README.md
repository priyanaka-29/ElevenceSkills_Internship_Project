```md id="animalall4"
# AI Animal Detection System

## Description
This project detects animals using YOLOv8 and OpenCV.

## Features
- Upload Image Detection
- Realtime Camera Detection
- Multiple Animal Detection
- Carnivorous Animal Highlighting
- GUI Interface

## Carnivorous Animals
- dog
- cat
- bear

## Technologies Used
- Python
- YOLOv8
- OpenCV
- Tkinter

## How to Run

### Install Libraries
pip install -r requirements.txt

### Run GUI
python gui.py

### Run Realtime Detection
python realtime.py
```
