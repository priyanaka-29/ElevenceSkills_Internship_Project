# AI-Based Car Colour Detection and Traffic Monitoring System

## Project Overview

This project is an AI-powered car colour detection and traffic monitoring system using Deep Learning and Computer Vision. The system detects cars, predicts their colour, counts vehicles and people, and highlights blue cars using red rectangles.

## Features

* Car colour prediction
* Vehicle counting
* People counting
* Real-time webcam detection
* GUI with image preview
* Accuracy graph
* Confusion matrix
* CNN model training
* YOLO object detection

## Technologies Used

* Python
* TensorFlow
* OpenCV
* YOLOv8
* NumPy
* Tkinter
* Matplotlib
* Seaborn

## Dataset

Car Color Classification Dataset from Kaggle.

## Methodology

1. Data preprocessing
2. CNN training
3. YOLO object detection
4. Real-time traffic analysis
5. GUI integration

## Results

* Accurate car colour detection
* Real-time vehicle counting
* Person counting at traffic signals
