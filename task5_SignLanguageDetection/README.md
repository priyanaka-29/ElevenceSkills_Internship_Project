# Real-Time Sign Language Detection System

## Project Overview

This project is an AI-based real-time sign language detection system developed using Deep Learning and Computer Vision techniques. The system can recognize sign language gestures from uploaded images and live webcam video.

## Features

* Real-time webcam detection
* Upload image prediction
* CNN-based deep learning model
* Confidence score display
* Voice output
* Professional GUI
* Accuracy graph
* Confusion matrix
* Time-restricted execution (6 PM to 10 PM)

## Technologies Used

* Python
* TensorFlow
* OpenCV
* NumPy
* Tkinter
* Matplotlib
* Seaborn

## Dataset

ASL Alphabet Dataset was used for training the model.

## Methodology

1. Data preprocessing
2. Image augmentation
3. CNN model training
4. Real-time prediction
5. GUI integration

## Results

* High prediction accuracy
* Real-time gesture recognition
* User-friendly interface
